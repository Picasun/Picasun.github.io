华东师范大学金融科技创业团队招人

Picasun Lv4
  2024-09-12 18:41:28 2024-09-12 18:41:28 Created   2026-10-09 09:28:25 2026-10-09 09:28:25 Updated  

最优秀的团队寻找最优秀的你！我们是年轻化扁平化的团队，正在寻找对区块链技术和去中心化应用充满热情的技术及投研实习生！如果你希望和区块链行业最优秀的团队一起共事，简历投递邮箱 51265902090@stu.ecnu.edu.cn

1. web3 区块链量化实习生

【岗位职责】

参与区块链量化系统/策略的开发及优化。

【基本要求】

  1. 成绩优异，在校期间绩点前30%；
  2. 至少掌握一门以上编程语言，偏好python；
  3. 工作时间自由，每周2-3个半天现场办公即可（中北校区双创大楼，可含周末）；
  4. 对区块链知识有热情，主观能动性强（最重要）；

【加分项】

  1. 计算机或统计等相关专业；
  2. 区块链或量化金融相关经验；

【待遇】

  1. 实习补贴+项目奖金，具体面议；
  2. 团队核心成员一对一带队指导，在实际项目中积累丰富的开发经验；
  3. 学术界与产业界相结合的前沿研究主题，可能收获竞赛或科研经历；
  4. 试用期一个月；

2. web3 区块链投研实习生

【岗位职责】

参与区块链项目的研究分析，形成项目研报，支持团队决策。

【基本要求】

  1. 成绩优异，在校期间绩点前30%；
  2. 掌握数据信息搜集等基本技能，具有较强的研究分析功底；
  3. 工作时间自由，每周2-3个半天现场办公即可（中北校区双创大楼，可含周末）；
  4. 对区块链行业有着极大的热情，热爱思考，具备结构化思维和逻辑思考能力；

【加分项】

  1. 有一定的区块链行业知识（对各大公链，DeFi，NFT，Layer2 有基础的理解）；

【待遇】

  1. 学术界与产业界相结合的前沿主题；
  2. 团队核心成员一对一带队指导，在实际项目中积累丰富的投研经验；
  3. 学术界与产业界相结合的前沿研究主题，可能收获竞赛或科研经历；
  4. 试用期一个月。

【公司简介】
我们是一个专注于区块链技术和量化交易的公司，主要从事区块链量化，链上安全审计，区块链数据库开发。我们的核心团队主要来自于华东师范大学，具有强大的顾问团队，丰富的项目开发经验和前沿的行业视野。我们旨在通过最新的区块链技术，赋能金融科技，建设链上生态。
